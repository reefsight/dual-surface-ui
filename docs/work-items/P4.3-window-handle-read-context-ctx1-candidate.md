## Outcome and boundaries

CTX1 adds a source-owned label to the first failing window-handle read. The
[original negative](../evidence/p4.3-r1-native-first-failure-2026-10-14.md)
establishes `initial/setup/window-handle/not-supported/InvalidObservation`,
but does not identify the source edge or explain the operating-system cause.
The label narrows a subsequent investigation; it cannot establish ownership,
authorize an action, accept S2, or renew the consumed R1 execution entry.

Keep the existing property result, exception identity, getter count, deadline
order, ownership guards, traversal, mutations, resource limits and success
contract. In particular, retain `ignoreDefaultValue: true` and the refusal of
`AutomationElement.NotSupported`. Do not substitute zero, use a default value,
add a getter/probe, relax a boundary, or infer a windowless wrapper.

The first release still requires qualified Rust native. This managed diagnostic
does not select a language or replace P4.4, P4.5, real-host P4.6 or P4.7.

unknown route/context values before invoking a supplied read/identity delegate;
do not accept a caller-defined string route.

Replace only the three window-handle `Read<int>` expressions with a dedicated
`ReadWindowHandle(peer, context)` helper. It uses the same existing property
getter and diagnostics sequence. Ordinary `Read<T>` must no longer accept the
window-handle property without context. Collector source stays unchanged: its
failures remain coarse `capture-call`, not fabricated setup contexts.

## Primary latch and read sequence

Set the passive context only for the single window-handle `ReadRequired<int>`
invocation, not an enclosing `Guard`, `Identity`, `Fence` or operation. A Guard
reads process ID first; that earlier failure must carry null context.

The sequence remains `requireLive -> one getter -> requireLive -> typed check`.
The innermost catch snapshots site and context into the immutable primary
before restoring both transient fields in `finally`. This includes before-read
and after-read deadline failures and getter exceptions. A post-read deadline
refusal takes precedence over classifying a returned unsupported/malformed
value. A successful annotated read restores context before later code runs.

Outer catches, subsequent attempted operations, admission callbacks, cleanup
faults and publication must not replace or reconstruct the primary. Retain
the independent once-only cleanup/publication behavior and CreateNew output.
No exception text, stack, provider value or `ToString()` output is retained.

## Exact private negative contract

Use schema `0.1`, new kind `p4.3-native-capture-suite-ctx1-failure`, and exactly
these fifteen required flat fields:

```text
schemaVersion kind sourceDigest collectorBinaryDigest fixtureBinaryDigest
case stage site classification code cleanupCode recordedAt
admissionCheck admissionGuard readContext
```

Retain 4096 original UTF-8 bytes, depth2, tokens32 and string128. Fifteen
key/value pairs consume thirty tokens plus the two root-object tokens: exactly
32. Do not increase a cap or add another field. Reject BOM, malformed UTF-8,
ill-formed decoded strings, duplicate decoded keys (including escaped aliases),
unknown/missing fields, nesting, arrays, booleans, numbers and trailing content.
Retain existing pin, calendar/time, location, classification/code, cleanup and
constructor-admission-pair rules.

| Combination | Rule |
| --- | --- |
| `site == window-handle` | A recognized non-null `readContext` is required |
| Any other/null site | `readContext` must be explicit null |
| Any non-null context | Stage `setup`; fixed non-bootstrap case; both admission fields null |
| `container-*`, `container-chain-*`, `selection-container-*` | Only `selection`, `tab`, `combo` |
| `walk-cross-root-*` | Only `combo`, `modal-cancel`, `modal-confirm` |
| Other recognized contexts | All unchanged22 case IDs; every case uses Reset |

The separate fixed CTX1 reader never falls back to D1/D2. Legacy readers must
reject CTX1 bytes; CTX1 rejects legacy kinds. Candidate-only legacy encoding
helpers, if retained for adapted regression tests, must refuse non-null context
rather than silently strip it. Production publication uses only CTX1.

Keep the owned `p4.3-capture-<GUID>/{first,repeat}/failure.json` path grammar,
original-byte digest, no-link/hardlink/identity/recheck rules, bounded output
and `nativeAccepted: false`. Read no partial capture, recorder or report after
failure. A valid source label is not a cryptographic signature: a writer able
to forge a whole admissible record can substitute a valid label. Producer
provenance and original-byte review remain required.
