# P3.2 — Policy-Safe Playwright Fallback

Status: Accepted for implementation

Phase: 3 — Ecosystem, reliability, and evaluation

Required approver: Repository maintainer

## Problem and user outcome

Agents need a deterministic way to inspect and operate legacy pages that do
not integrate Dual Surface UI or WebMCP. The fallback must retain the same
authorization, confirmation, revision, replay, verification, redaction, and
audit guarantees as the DOM surface even though Playwright has elevated
browser authority.

P3.2 adds an optional semantic Playwright surface and a constrained visual
candidate selector. A host reviews the allowed targets and actions; the page
does not need to import package code.

## Delivery slices

1. Extract a backend-neutral internal lifecycle and prove DOM behavior parity.
2. Add the optional semantic Playwright subpath with explicit bindings.
3. Add bounded, masked visual candidate selection that can return only a
   current semantic node ID.
4. Run three-engine browser, adversarial, packaging, and frozen-contract gates.

P3.2 is not complete until all four slices and their evidence pass.

## Scope

- additive `dual-surface-ui/playwright` package subpath;
- caller-owned Playwright `Page` and explicit allowed top-level origins;
- exact accessible role/name targets with trusted stable package IDs;
- closed operations for click, fill, check/uncheck, and option selection;
- normalized, deterministic, bounded snapshots of explicitly bound controls;
- shared core lifecycle for policy, confirmation, preconditions, replay,
  verification, normalized failures, and audit;
- monotonic revision/generation invalidation on mutation and navigation;
- optional masked, ephemeral image callback that selects only from current
  semantic candidates;
- Chromium, Firefox, and WebKit fixture evidence;
- isolated packed-consumer checks with and without the optional peer.

## Non-goals and prohibited changes

- no automatic arbitrary-page action catalog or inferred business authority;
- no generic selectors, internal ARIA refs, `nth`, coordinates, raw keyboard or
  mouse, arbitrary `Locator`, callback access to `Page`, or script evaluation;
- no browser launch, URL navigation, authentication, profile reuse, cookies,
  storage, transport, or credential acquisition owned by the package;
- no frames in the first slice and no implicit cross-origin traversal;
- no password, OTP, token, payment, WebAuthn, certificate, file, download,
  clipboard, permission, popup, or dialog action;
- no raw ARIA JSON, unmasked screenshot, selector, handle, browser state,
  exception, stack, or filesystem path in public results or evidence;
- no success based only on a Playwright method returning;
- no root export, frozen schema, package version, release, or Phase 4 change.

## Public API candidate

```ts
import type { Page } from "playwright-core";

export interface PlaywrightSemanticTarget {
  role: PlaywrightAriaRole;
  name: string;
}

export type PlaywrightOperation =
  | { type: "click" }
  | { type: "fill" }
  | { type: "set-checked"; checked: boolean }
  | { type: "select-option" };

export interface PlaywrightActionBinding
  extends Omit<AgentActionDefinition, "handler"> {
  operation: PlaywrightOperation;
}

export interface PlaywrightElementBinding {
  id: string;
  target: PlaywrightSemanticTarget;
  description?: string;
  sensitive?: boolean;
  actions: Readonly<Record<string, PlaywrightActionBinding>>;
}

export interface PlaywrightVisualRequest {
  image: Uint8Array;
  mimeType: "image/png";
  candidates: readonly Pick<AgentElementSnapshot, "id" | "role" | "name">[];
}

export interface PlaywrightSurface {
  snapshot(options?: { signal?: AbortSignal }): Promise<AgentSnapshot>;
  perform(
    request: AgentActionRequest,
    options?: { signal?: AbortSignal },
  ): Promise<AgentActionResult>;
  performSafe(
    request: AgentActionRequest,
    options?: { signal?: AbortSignal },
  ): Promise<AgentActionOutcome>;
  selectVisualCandidate?(
    options?: { signal?: AbortSignal },
  ): Promise<string | undefined>;
  dispose(): void;
}

export function createPlaywrightSurface(
  options: PlaywrightSurfaceOptions,
): PlaywrightSurface;
```

The concrete role union and option budgets are frozen during implementation
review. Options reuse the trusted lifecycle callbacks from `AgentSurfaceOptions`
and additionally require `page`, `surfaceId`, `allowedOrigins`, and frozen
bindings. Visual selection is absent unless the host explicitly supplies a
callback and masking configuration.

## Trust boundaries and lifecycle

The caller, page content, accessibility names, ARIA properties, screenshots,
visual callback, and action input are untrusted. The caller-owned Playwright
controller, host bindings, origin allowlist, lifecycle callbacks, and package
code form the trusted boundary. Browser context cookies, storage, permissions,
profiles, and credentials remain outside the contract and are never observed
or serialized.

For each request the adapter captures the current generation, validates the
strict envelope, binds trusted action metadata, runs the shared policy and
confirmation path, re-observes after asynchronous gates, checks preconditions,
executes one allowlisted primitive, observes again, verifies the authoritative
effect, then emits a normalized result and redacted audit events. Cancellation
is honored before execution starts; after execution starts the adapter finishes
verification and audit without claiming rollback.

## Acceptance criteria

| ID | Requirement |
|---|---|
| AC-01 | DOM and Playwright execution use one internal lifecycle coordinator; existing core behavior and the frozen root contract remain unchanged. |
| AC-02 | Construction requires a caller-owned page, valid opaque surface ID, non-empty origin allowlist, and frozen explicit bindings. Invalid or mutable configuration fails closed. |
| AC-03 | Snapshot output is deterministic, bounded, schema-valid, detached, and redacted; raw ARIA data, selectors, handles, frames, cookies, storage, and credentials are absent. |
| AC-04 | Only exact public semantic locators are used and each executable target must resolve uniquely. Missing, duplicate, hidden, disabled, detached, or replaced targets are unavailable or fail safely. |
| AC-05 | Requests bind the current surface, monotonic revision, navigation epoch, origin, target, and action. Navigation, origin change, target replacement, or semantic ABA makes retained requests stale. |
| AC-06 | Policy, trusted confirmation, preconditions, replay/conflict, failure normalization, verification, and audit match DOM surface outcomes. Page content, dialogs, and visual output cannot grant authority. |
| AC-07 | After every asynchronous gate the adapter rechecks revision, origin, exact target, action availability, visibility, enabled state, and disposal before mutation. |
| AC-08 | The adapter exposes only click, fill, set-checked, and select-option operations, uses default actionability, and never accepts a generic selector, coordinate, script, navigation, keyboard, mouse, file, download, clipboard, permission, popup, or dialog action. |
| AC-09 | Credential/sensitive controls expose no value or fallback action. The credential corpus produces zero secret bytes and zero mutation. |
| AC-10 | Top-level origin mismatch and every frame are denied in the first slice. Unexpected navigation, popup, download, dialog, close, crash, or disconnect invalidates the generation and cannot continue implicitly. |
| AC-11 | Playwright completion alone never returns success; deterministic native state or a trusted declared effect must verify from current state. |
| AC-12 | Keyed concurrent requests execute once, conflicting reuse fails, stale unkeyed writes cannot both mutate, and replay scope cannot cross principal, origin, page, or context. |
| AC-13 | Visual mode is explicit and returns only an allowlisted current node ID. All sensitive controls and excluded frames are masked; inability to mask disables visual output; images are bounded, ephemeral, and never logged or retained. |
| AC-14 | Chromium, Firefox, and WebKit fixtures prove action parity, denial/confirmation, stale and ambiguous targets, target swap, redaction, origin/frame isolation, unexpected browser effects, cancellation, concurrency, and authoritative verification. |
| AC-15 | Playwright is an optional peer/subpath; root import has no Playwright dependency or side effect, package contents contain no browser binary/profile/trace/screenshot, and packed consumers pass at the minimum and current allowed peer versions. |
| AC-16 | Typecheck, build, full deterministic gate, frozen 32/6/5 contract, audit, package inspection, diff check, and independent security/API reviews have no unresolved critical/high finding. |

## Verification plan

```text
npm run typecheck
focused lifecycle and Playwright suites
npm run test:browser
npm run test:gate
npm run contract:check
npm audit --json
npm pack --dry-run --json
fresh packed consumer: root import without Playwright
fresh packed consumer: /playwright at minimum and current allowed peer
git diff --check
independent security and Playwright API/package review
```

Browser evidence records the Playwright version, managed browser revision and
version, Node version, OS, and unsupported behavior. Passing managed Chromium,
Firefox, and WebKit does not claim installed Chrome, Edge, or Safari support.

## Rollback and disable strategy

Do not import the optional subpath or do not configure visual selection.
Disposing a surface invalidates every retained generation and prevents new
actions. Reverting the additive subpath removes the adapter without data
migration, browser profile cleanup, or persistent state. The internal lifecycle
refactor must remain independently revertible until parity evidence passes.
