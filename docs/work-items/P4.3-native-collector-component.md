## Implemented source boundary

The isolated `NativeCaptureHarness` links the unchanged copied-data/subject/
semantic-session foundation. Native admission anchors the newly owned Process,
birth, token, main HWND and its sole native owning thread. MainWindowHandle is
used once at binding, never refreshed into an enabled modal. Active local
session, exact worker/subject user/session/integrity, non-elevation/UIAccess,
WinSta0 and Default/input desktop checks retain bounded buffers. Borrowed
thread-desktop handles are not closed. Only exact-thread EnumThreadWindows is
used, with64 callbacks counted before filtering, callback fault/overflow
containment and explicit completion. Every additional visible/enabled candidate
must be the one expected direct-owned auxiliary; competing/unprovable subjects
refuse. Both complete candidate frames must match before publication. Modal
owners may be disabled; popup and typed Window root proof remain distinct.

The collector has one shared10-second budget through admission, both root
trees, selected-peer ancestry, node/text accounting, projection and final
fences. The immutable foundation's independent pure checks cannot reset this
outer deadline. Nodes256, roots2, depth16, children64, auxiliary64 within256,
text131072, private runtime-ID parts32 and all existing snapshot/report caps are unchanged. Runtime IDs
are salted private hashes; every identity getter has an ownership-first gate.
Precisely admitted auxiliary roots may be pruned from the main walk by native/
current-instance proof only, never by labels or oracle nodes.
Every visited peer has an explicit typed native-handle boundary check before
content: nonzero handles must have current owned PID/thread/desktop and native
GA_ROOT equal to admitted main/auxiliary. Hidden/disabled unadmitted HWNDs or
different-thread roots cannot gain admission through Control View ancestry.
Zero is logical membership only, not a root proof; unsupported/malformed handle
observations refuse rather than defaulting to zero. OS checks remain sequential.

Explicit Boolean/NotSupported classification precedes Name/content/patterns.
Sensitive or any unknown basic flag remains structural-only. Only seven typed
semantic families are inspected; no mutating method is present. Selection uses
explicit typed SelectionProperty arrays, at most one peer; chosen peers need
basic safety, owned root ancestry and combined/auxiliary accounting before
pattern/state reads, current expected SelectionContainer and selected=true.
Known-safe private/unreviewed peers are retained in reciprocal consistency.
Every copied SelectionItem, not only the chosen peer, has a fresh nullable-state/
container/pattern fence. Radios have no invented Selection container. Unknown
optional state stays unknown; malformed kinds or lost relations refuse.
Fresh parent/selected/container comparisons independently gate both operands'
PID/native boundary, then compare bounded private identities; they do not call
Automation.Compare's extra unbounded runtime-ID getter. Injected comparison
callbacks cover foreign/malformed operands and failed boundary proofs.

Failure invalidates the semantic session; disposal permanently retires it and
refuses a later serial Capture before admission/provider or host-fence calls.

## Executable scope and review fixes

The entry point accepts **only `--unit`**. It never constructs native admission
or performs native collection; the disposed-lifecycle unit calls Capture only
to prove its first guard, before admission/fence/provider access.
The existing cached SDK10.0.401 builds the component;
the owned unit worker keeps its30-second deadline. Strict UTF8 decoding retains
BOM for refusal; a separate bounded JS duplicate-key/shape parser exposes only
the closed unit summary. Raw stdout/stderr/parser exception details are not
displayed. Output is post-buffered; the PowerShell/Node bridge is a reencoded
unit summary, not native artifact-byte provenance. It has no model or endpoint.

Actual preliminary security/accessibility/package agents found ownership-first
identity ordering, selected ancestry/accounting before reads, nonchosen/private
container fence gaps, competing ownerless windows and loose summary parsing.
Root remediated these and added deterministic policy/callback/fence/summary
negative cases. Those injected callbacks and pure native facts are **not real
OS/UIA/provider proof**. Final actual source review must bind its exact target;
root cannot supply independent dispositions.
