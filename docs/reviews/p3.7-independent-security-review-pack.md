## Required manual scope

The independent reviewer must inspect the P3.7 implementation commit, ADR
0013, all 23 hostile cases, the threat-control matrix, the deterministic test
harness, package leak check, and the redacted report. At minimum, the review
must cover:

- page, tool, MCP metadata, CLI, trace, and model-output injection remaining
  untrusted data;
- principal, origin, surface, action, revision, target, page/context, and
  idempotency/replay scope binding;
- stale-state, target replacement, semantic ABA, and visual allowlist checks
  occurring before mutation;
- trusted policy and confirmation callbacks being authoritative rather than
  prompt text;
- redaction across snapshot, trace, model context, output, report, process
  output, and package channels;
- absence of private adversarial fixtures and sentinel values from the npm
  package.

## Reviewer output

After completing the manual review, the independent reviewer must provide a
stable reviewer ID, explicitly confirm independence from the P3.7
implementation, list every finding and disposition, and state whether any
critical/high finding remains unresolved. The canonical record belongs at
`docs/reviews/p3.7-independent-security-review.json` and must validate with:

```text
npm run phase3:evidence:validate -- security docs/reviews/p3.7-independent-security-review.json
```

An approval is valid only when the record is schema-valid, the reviewer is
independent, `unresolvedCriticalHigh` is zero, and the disposition is
`no_unresolved_critical_high`. The repository maintainer must not create or
approve this record on the reviewer's behalf.
