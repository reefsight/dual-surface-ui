## Required implementation boundary, not a runtime finding

The following are part of the approved design and must be demonstrated in the later source/evidence review:

1. Map only the exact UIA `NotSupported` sentinel to internal unknown. A nullable internal field must not make raw provider `null`, a wrong type or an exception acceptable. Do not use default false, a control label/type/ID or property enumeration as safety evidence (`P4.3-implementation-slices.md:103-107`).
2. Unknown password/enabled/offscreen nodes remain bounded structural membership only: no pattern reads, actionable candidate or receipt. Sensitive nodes stay pattern-free; each child target independently needs known nonsensitive/enabled/onscreen observations and complete current graph/OS/window admission (`:108-115`).
3. Keep Value and Range read-only observations separate. Value eligibility needs its own explicit known-writable observation; RangeValue eligibility needs its own. Unknown must not become writable, and a lossy OR/shared flag must not substitute for per-pattern requirements. Unrelated semantic patterns retain their existing independent requirements (`:116-119`).
4. Pattern suppression is not proven pattern absence. A same-correlation, reviewed-type, current-container unknown-safety node must block discovery even if a known-safe sibling advertises the requested pattern. Do not reuse the old pattern-only candidate filter to silently discard the unresolved sibling. Different-type structural wrappers can coexist without becoming action authority (`:120-124`).
5. Independently fingerprint every flag with unknown distinct from true and false; each transition invalidates old receipts. Defensive copy, rooted membership, budget and unknown-plus-pattern-forgery checks remain mandatory. Executable regressions must cover all three core unknown flags, same-type ambiguity, different-type coexistence, per-pattern read-only unknowns, transitions and absence of pattern reads (`:125-134`).
6. Keep those fields inside the identity reference. No public schema/protocol field, error/status, SDK export, retained pattern peer or new caller-provided selector may escape. Preserve ordinary host admission, fixture/binary pinning, unchanged deadlines, no failed-run-to-success retry admission and later slice gates (`:136-142`).
