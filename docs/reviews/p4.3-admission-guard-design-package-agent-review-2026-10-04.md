## Passive observer and faithful guard meaning

The future observer accepts only the two closed enums, not exception objects,
native values, process/desktop/window identities, provider data or a generic
operation callback. It is enabled for this constructor only and cleared in
finally on success or failure. Later Observe/context/peer checks and cleanup
must remain coarse. A serial constructor-scoped implementation must not leak
observer/context through shared state into another admission or later fence.

An existing explicit Unavailable guard notifies once and still throws the same
closed refusal unconditionally, including when the optional observer is absent,
throws or supplies invalid input. The suite observer performs only pair/context
validation and one immutable assignment: no IO/logging, clock/deadline call,
native/provider operation or exception interpolation. Invalid or already-latched
input cannot partially publish fields, replace a primary or authorize continuation.
Actual future source review must prove these properties at production callsites;
passing synthetic callbacks alone will not prove unchanged native call order.

The table is a host-owned check/group assertion. The original compound desktop
guard is `desktop == 0 || ObjectName(desktop, budget) != "Default"`; a null
handle short-circuits without a name read. Final `desktop-name-or-null` correctly
preserves that ambiguity and does not claim a measured name mismatch. If the
existing right-hand ObjectName operation itself refuses, `name-query` describes
that distinct existing guard. No splitting, re-evaluation or extra query is
authorized. Token/session/window compound groups have the same limitation.

SDK/managed faults and deadline refusals that do not pass through an existing
explicit guard retain coarse classification, with null new fields. The last
entered check is not evidence that its guard refused. Callback errors cannot
overwrite original guard results or deadline precedence. Existing allocation,
short-circuit/read order,10/30/240 budgets and once-only owned cleanup remain.
