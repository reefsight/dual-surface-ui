# P4.2 Windows Host Entry Preflight — 2026-09-22

Status: Read-only environment evidence; not P4.2 runtime or native-conformance
proof

This preflight records only non-identifying host capabilities needed to assess
the P4.2 entry gate. It intentionally excludes the machine name, username,
user path, network identity, device identifiers, and production data. No SDK,
compiler, workload, or package was installed.

An authorized WinGet attempt for Microsoft .NET SDK `10.0.401` subsequently
verified the installer hash but ended with exit code `1602` when the
administrator-elevation flow was cancelled. `dotnet --list-sdks` remained
empty afterward. See the
[Windows build-host handoff](p4.2-windows-build-host-handoff-2026-09-22.md).

The legacy Windows registry product-name field reported `Windows 10 Pro`, while
the operating-system management interface reported `Microsoft Windows 11 Pro`.
The version and build values agree; the Windows 11 caption is used here and the
registry-label discrepancy remains visible rather than silently normalized.

## Read-only checks

The preflight queried selected OS version fields, runtime architecture and
culture, the existence/version of `%WINDIR%\\System32\\UIAutomationCore.dll`,
`dotnet --list-sdks`, `dotnet --list-runtimes`, `rustc --version`, and
`cargo --version`. Output was manually constrained to the fields above before
being recorded.

`dotnet --version` also failed with `No .NET SDKs were found`, confirming that
the installed runtimes are insufficient to build the proposed WPF fixture.

## Gate consequence

- The host satisfies the read-only Windows/UI Automation availability
  precondition for P4.2 planning.
- The host does not yet satisfy the source-build precondition because no .NET
  SDK is installed.
- ADR 0016 was explicitly accepted by `Pitchayut586` on 2026-09-22, so the
  narrowly required SDK installation and fixture source implementation may
  proceed.
- This preflight does not prove WPF provider behavior, real UI Automation tree
  capture, semantic actions, repeatability, redaction, or any P4.2 acceptance
  criterion beyond environment availability.
