## Administrator-run installation

From an elevated PowerShell session on the approved Windows build host:

```powershell
winget show --exact --id Microsoft.DotNet.SDK.10 --accept-source-agreements
winget install --exact --id Microsoft.DotNet.SDK.10 --version 10.0.401 --scope machine --silent --accept-package-agreements --accept-source-agreements --disable-interactivity
```

Do not install Visual Studio, unrelated workloads, Rust, Cargo, preview SDKs,
or global tools for P4.2. If WinGet is unavailable or the frozen package no
longer resolves, stop and record the condition instead of downloading from an
unreviewed mirror.
